# v0.1 live validation

Date: 2026-09-02

This record covers one controlled two-launch validation of the source-only
`legacy-v0.1` profile with Steam AppID `2440510` and `GE-Proton11-3-FM` on the
tested Arch Linux and KDE Plasma system. The observer confirmed the game-facing
results at the UI. The transaction was accepted only after both game exits left
the service, socket, and launcher ownership tokens absent.

No account name, remote-player identity, XUID, authorization value, invite URI,
credential, or raw runtime log is recorded here. The separately supplied
licensed Microsoft threading runtime was checked only for existence; it was not
read, copied, hashed, or distributed.

The live transaction used the pre-publication candidate before two internal
planning documents were removed. The final public Xodus revision differs only
by that documentation removal: its runtime/source diff is empty and a fresh
release build reproduced all three installed Xodus hashes below. A final
provenance-only transaction bound the unchanged artifacts to the public source
revision and finished in the `accepted` state. The transactions installed only
the ten allowlisted open-source artifacts and retained the reviewed pre-install
state for recovery.

## Lifecycle evidence

Before the first launch, the user service was inactive and static and the Xodus
socket was absent. The launcher started the service for the game session. After
each observed game exit, the service was inactive and the socket, pending owner
token, and active owner token were absent. The second launch succeeded without
a system reboot, and the final exit repeated the same clean state.

This is evidence for the exact tested profile and hashes only. It is not a
claim of general Proton, Wine, distribution, hardware, or future game-build
compatibility.
