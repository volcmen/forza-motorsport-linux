# Forza Motorsport Linux tools

This repository is experimental and targets Steam AppID `2440510` with the
known `GE-Proton11-3-FM` build. It documents a source-only, user-local
integration boundary for Linux; it does not claim ordinary upstream Proton
support.

No Microsoft binaries, credentials, authentication material, game assets, or
third-party binary downloads are provided. A user-supplied runtime from a
licensed Windows installation remains their responsibility.

Installation is not ready until the remaining implementation and verification
tasks land. Do not treat this initial policy foundation as an installable
release.
